Get class data from UoS

The UoS registration site doesn't let other pages read it, so a small bookmark runs on the UoS Class Search page, grabs the sections you ask for, and gives them back to you as a file and on your clipboard. No login needed. It only reads public class search data.

Python script (easiest)

Put uos_classes.py next to this file and run python uos_classes.py --term 202620. It grabs every class for the term and opens a copy of this planner with the data already inside. Add --wait 15 to keep checking every 15 minutes until the classes are published.

Bookmark (set up once)

  1. Show your bookmarks bar (Ctrl+Shift+B).
  2. Drag this button onto it: Grab UoS classes
  3. Open the UoS Class Search page and click the bookmark.
  4. Pick the term (Spring 2026/2027 is 202620) and type your course codes, or ALL for every subject (takes a minute or two).
  5. Come back here and click Paste data, or Import file and choose the downloaded uos-classes-…json.
